# Azure Cloud Engineering Portfolio

This repository documents my progression from IT operations/support into Azure cloud engineering.

The goal is not to collect tutorial screenshots. Each project is built to demonstrate practical engineering habits: requirements, architecture, security, deployment, troubleshooting, validation, automation, documentation, cost awareness, and lessons learned.

## Learning loop

**Study → Build → Break → Diagnose → Automate → Document → Explain**

## Portfolio roadmap

1. `01-governance-landing-zone/` — resource organization, tagging, budgets, RBAC, Azure Policy
2. `02-identity-least-privilege/` — identity, groups, scoped access, least privilege, access review
3. `03-networking/` — VNets, subnets, NSGs, routing, DNS, connectivity troubleshooting
4. `04-compute-storage/` — VMs/App Service, storage, availability and operational controls
5. `05-monitoring-incident-response/` — Azure Monitor, Log Analytics, alerts, KQL, failure investigation
6. `06-backup-recovery/` — backup, restore, resiliency, validation
7. `07-infrastructure-as-code/` — Bicep/Terraform, repeatable deployment and teardown
8. `08-automation/` — PowerShell/Azure CLI automation
9. `capstone/` — integrated production-style Azure environment

## Standard for every lab

Each lab should include:

- Business reason
- Objective
- Architecture
- Build/deployment steps
- Security and governance decisions
- A deliberate failure test
- Diagnosis and evidence
- Fix and validation
- Cost/cleanup notes
- Interview story
- Lessons learned
